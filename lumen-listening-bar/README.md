# Lumen — Listening Bar

A complete, standalone one-page website for a fictional late-night listening bar in Tbilisi.

## Preview

Open `index.html` in a browser. No build step or dependencies are needed.

## Included

- Bespoke editorial art direction and CSS-built vinyl/interior artwork
- Responsive desktop and mobile navigation
- Animated ticker, record, hover states, and reduced-motion support
- Event programme and a reservation form interaction

The page is intentionally self-contained: no stock images or third-party UI kits are required. Google Fonts are the only external resource.
